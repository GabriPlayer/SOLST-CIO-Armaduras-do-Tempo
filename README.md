# SOLSTÍCIO: Armaduras do Tempo

Jogo de aventura de ficção científica (~5 horas) sobre viajantes no tempo que usam armaduras alimentadas pelo calor do Sol.

- Guião completo e personagens: [docs/GUIAO.md](docs/GUIAO.md)

## Jogar

Abre [game/index.html](game/index.html) no navegador (sem instalação). Campanha de 12 missões com mini-jogos, escolhas e 3 finais conforme a ligação entre Tim e Íris.

## Versão 3D

Projeto Unreal Engine 5.4 (C++) em [unreal/](unreal/README.md).
